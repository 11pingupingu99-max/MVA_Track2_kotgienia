# NAD+ - SIRT2 - BUBR1 conditional branch v1.0.0

Status: OPEN, conditional on F0 = ABUNDANCE-DOMINANT.

NB08R2 found no qualifying approved direct SIRT2 agonist in the audited drug-target layer.
That is not a test of whether increasing NAD+ availability can change BUBR1 abundance.
NB13 was transcriptomic and did not measure NAD+, SIRT2 activity, or BUBR1 protein abundance.

Mechanistic basis:
- SIRT2-dependent deacetylation of BUBR1 K668 opposes CBP-driven ubiquitination/degradation.
- In BubR1H/H mice, SIRT2 overexpression and NAD+ precursor intervention increased BubR1 abundance;
  SIRT2 overexpression increased median lifespan in that model.
- BUBR1 acetylation is residue/context dependent: K250 acetylation in prometaphase is required for normal checkpoint
  timing, so systemic NAD+/sirtuin manipulation cannot be assumed to have a single favorable sign.

Pre-specified conditions:
1. branch opens only if F0 is ABUNDANCE-DOMINANT;
2. abundance increase is not the success endpoint; missegregation per completed division and mitotic timing remain required;
3. mechanistic attribution requires SIRT2 epistasis: any putative NAD+-raising effect should disappear or materially attenuate
   when SIRT2 is suppressed;
4. nicotinamide and nicotinic acid are not interchangeable mechanistically;
5. no human intervention is proposed from this branch.

This branch is a cell-model hypothesis, not a treatment recommendation.

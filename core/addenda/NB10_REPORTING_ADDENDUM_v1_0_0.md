# NB10 reporting addendum v1.0.0

NB10 v1.0.1 tests operating characteristics of the decision architecture. It does not estimate drug efficacy.

For future result-bearing F0 experiments, a binary PASS/FAIL is insufficient. Report:
1. missegregation rate per completed division in each biological replicate;
2. control and intervention means;
3. absolute rate difference;
4. relative reduction;
5. 95% confidence interval preserving biological-replicate structure (replicate bootstrap or an appropriate hierarchical/binomial model);
6. inferential p-value;
7. completed-division output and apoptosis/selective-loss readouts;
8. clean-rescue decision after hard gates.

The simulation's 25% relative-reduction threshold is an operating point, not a validated therapeutic threshold.
